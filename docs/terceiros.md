## Licença do código autoral

O código autoral do BeastEmu para o qual Beast detém os direitos é distribuído sob MIT, com o aviso `Copyright (c) 2026 Beast`. O texto integral acompanha o repositório, o aplicativo instalado e o portátil no arquivo `LICENSE` da raiz. Os componentes da tabela conservam suas licenças e atribuições. [MIT](https://opensource.org/license/mit)

O pacote mantém o aviso histórico `Flutter-template-images.txt` das versões que utilizavam o ícone padrão do Flutter. Nesta revisão, os ícones de programa e instalação são exportações da prancha BeastEmu. As capas importadas pertencem à biblioteca de cada usuário. O emblema dracônico e o logotipo BeastEmu foram criados por geração de imagens no ChatGPT, sob a direção visual aprovada pelo responsável pelo projeto. As referências foram adaptadas para a interface, os ícones do Windows e o instalador. A [política da marca](../MARCA.md) identifica as artes e as permissões de uso. O código autoral permanece sob MIT. Os cartuchos gerados para os testes locais usam código de demonstração e um campo de logotipo vazio.
